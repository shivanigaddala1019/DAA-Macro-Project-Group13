# DAA Macro Project – Group 13

## Knapsack Problem Using Branch and Bound

### 📌 Project Overview

The Knapsack Problem using Branch and Bound is an optimization
problem that aims to maximize the total profit of selected
items without exceeding the given knapsack capacity.

This project implements the Branch and Bound technique to
explore promising solutions while eliminating branches that
cannot produce a better result.

### 🎯 Objectives

- Understand the Branch and Bound technique.
- Implement the 0/1 Knapsack problem using Python.
- Visualize the search tree and pruning process.
- Analyze the algorithm's working and performance.

### 🛠️ Technologies Used

- Python
- Matplotlib
- Git and GitHub
- AI tools for visualization

### ⚙️ Algorithm

1. Read the weights, profits, and knapsack capacity.
2. Calculate an upper bound for each promising node.
3. Explore the most promising nodes.
4. Prune nodes whose bounds cannot improve the current best profit.
5. Return the maximum achievable profit.
